# 線上訂單串接 Google Sheet 設定步驟

網站結帳送出後，訂單會寫進你的 Google 試算表，並寄 Email 通知。
這份設定**只需要做一次**，大約 10 分鐘。

## 1. 建立試算表並貼上程式

1. 打開 <https://sheets.new> 建立一份空白試算表，命名為「狠餃色訂單」。
2. 上方選單 **擴充功能 → Apps Script**。
3. 把編輯器裡原本的程式碼全部刪掉，貼上本資料夾 [`Code.gs`](./Code.gs) 的全部內容。
4. 按 **💾 儲存**（Ctrl+S）。

## 2. 初始化工作表

1. 在 Apps Script 編輯器上方的函式下拉選單選 **`setup`**，按 **▶ 執行**。
2. 第一次會跳出授權視窗：**審查權限 → 選你的 Google 帳號 → 進階 → 前往（不安全）→ 允許**。
   （這是你自己寫的程式，Google 才會顯示這個提示。需要的權限：編輯這份試算表、用你的信箱寄通知信。）
3. 回到試算表，會看到 4 個工作表：**訂單、訂單明細、商品、設定**。

## 3. 部署成網頁應用程式

1. Apps Script 編輯器右上角 **部署 → 新增部署作業**。
2. 左邊齒輪 ⚙ 選 **網頁應用程式**。
3. 設定：
   - 說明：`狠餃色訂單 API`
   - 執行身分：**我**
   - 誰可以存取：**所有人**
4. 按 **部署**，複製「網頁應用程式網址」（結尾是 `/exec`）。

## 4. 把網址接到網站

把剛剛的網址交給 Claude，或自己打開 `index.html`，找到這一行：

```js
const ORDER_API = '';
```

把網址貼進引號裡，例如：

```js
const ORDER_API = 'https://script.google.com/macros/s/XXXXXXXX/exec';
```

`ORDER_API` 留空時，網站是「示範模式」：結帳只會在畫面上模擬成功，不會真的送出。

## 日常使用

| 想做的事 | 在哪裡改 |
|---|---|
| 處理訂單 | 「訂單」工作表的 **狀態** 欄用下拉選單改：新訂單 → 製作中 → 可取餐／已出貨 → 已完成（顏色會自動變） |
| 改價格、下架商品 | 「商品」工作表改 **單價**，或把 **上架** 改成「否」。**網站上的價格也要一起改**，不然顧客看到的金額會和實收金額不同 |
| 新訂單通知寄到別的信箱 | 「設定」工作表的 **店家通知 Email** |
| 改運費、免運門檻 | 「設定」工作表 |
| 公休、暫停線上訂單 | 「設定」工作表的 **接受訂單** 改成「否」，顧客送出時會看到暫停公告 |
| 看今天營收 | 試算表上方選單 **🥟 狠餃色訂單 → 今日營收摘要** |

## 注意事項

- **金額以試算表的「商品」價格為準**：系統會用「商品」工作表重新計算金額，不採用網頁送來的價格，所以有人改網頁程式也無法竄改金額。
- **改了 `Code.gs` 要重新部署**：要到 **部署 → 管理部署作業 → ✏ 編輯 → 版本選「新版本」→ 部署**。這樣網址不會變，網站不用改。
- **寄信額度**：免費 Google 帳號每天可以寄約 100 封信，Google Workspace 帳號約 1,500 封。超過時訂單照樣會寫入，只是不寄信。
- **查詢訂單狀態**（之後要做「訂單查詢」頁面時可用）：
  `GET {網址}?action=status&no=訂單編號&phone=手機末三碼`
